## 🚀 Featured Engineering Projects

### 1. [SCOVIS Backend](https://github.com/RaihanHadriansyah21/scovis-backend) & [SCOVIS Frontend](https://github.com/RaihanHadriansyah21/scovis-frontend)
> **Direct Image-Based Exam Score Classification Oversight System**
- **Tech**: Python, FastAPI, Redis Queue (RQ), TensorFlow (72 H5 Model Ensemble), Next.js 16 App Router, React 19, TypeScript, Supabase SSR Auth.
- **Description**: Asynchronous AI scoring engine and web interface for handwritten exam sheet classification with human-in-the-loop lecturer verification.

### 2. [DermaScan](https://github.com/RaihanHadriansyah21/DermaScan_Project)
> **AI-Powered Skin Lesion Risk Stratification System**
- **Tech**: Multi-Task EfficientNetV2 + CBAM Attention, TFLite, FastAPI, React 18, Vercel, Railway.
- **Description**: Capstone decision support system executing multi-task binary risk classification and 5-class lesion taxonomy with TFLite model optimization.

### 3. [QuizInt Mobile](https://github.com/RaihanHadriansyah21/quizint-learning)
> **Gamified Mobile Learning & Assessment Platform**
- **Tech**: Flutter, Dart, Provider, Supabase Cloud, Native Biometrics (`local_auth`), Camera Scanner (`mobile_scanner`), PDF Exporter.
- **Description**: Interactive EdTech mobile application delivering gamified quiz runs, streak power-ups, QR onboarding, and automated PDF gradebook generation.

### 4. [Indonesian Sentiment Analysis](https://github.com/RaihanHadriansyah21/gojek-sentiment-analysis-ml-dl)
> **Comparative NLP Benchmark: Classical ML vs Deep Learning**
- **Tech**: Python, Scikit-Learn, TensorFlow, Sastrawi Indonesian NLP, TF-IDF, LSTM.
- **Description**: Indonesian text sentiment classification pipeline comparing TF-IDF + SVM/Random Forest against Word Embeddings + LSTM on user review datasets.
